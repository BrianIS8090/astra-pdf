# Установщик Astra PDF

Inno Setup 7.1.0, Windows 11 x64 (build 22000 и новее). Установка для текущего пользователя без повышения прав. Установщик и EXE приложения не подписаны сертификатом издателя.

## Поведение в Windows

- Постоянный AppId `{4C5F0E6B-825B-4A27-8A96-3D71CD9DBF62}` и папка `%LOCALAPPDATA%\Programs\Astra PDF`. Повторный запуск использует предыдущую папку и заменяет файлы, включая предварительные версии с одинаковой числовой версией ресурса EXE.
- Собственный ProgID `AstraPDF.Document`, `Applications\AstraPDF.exe`, `.pdf\OpenWithProgids`, `Software\AstraPDF\Capabilities` и `Software\RegisteredApplications` в HKCU. Команда открытия содержит кавычки и для EXE, и для документа.
- После установки предлагается `ms-settings:defaultapps?registeredAppUser=Astra%20PDF`. Настройки также доступны по ярлыку в меню «Пуск». Некоторые сборки Windows открывают общий список: тогда нужно ввести `.pdf` в верхнем поле и выбрать Astra PDF. Финальный выбор делает пользователь средствами Windows.
- Нет записи в UserChoice, назначения PDF через обход хеша, изменения чужих обработчиков или прав администратора. Тихая установка не открывает приложение или настройки.
- Удаление убирает собственные файлы, ярлыки и регистрацию. Для общих ключей удаляются только собственные значения. PDF пользователя, добавленный в папку приложения после установки, сохраняется; штатный демонстрационный PDF принадлежит комплекту и удаляется.

## Сборка

Из корня проекта в PowerShell, после сборки приложения:

```powershell
.\scripts\setup-installer.ps1
.\scripts\assemble.ps1 -Destination .\dist\installer-payload
.\scripts\build-installer.ps1 -PayloadDirectory .\dist\installer-payload
```

Для публикации передайте в `PayloadDirectory` комплект, прошедший проверку приложения. Скрипт сверяет версию EXE с version.json и, если имеется, проверяет SHA256.json. Поддерживаются форматы контрольных сумм локального и публичного комплекта. Он не заменяет проверку приложения и не меняет исходные файлы комплекта.

Компилятор загружается с официального релиза, проверяется закреплённой SHA-256 и подписью Pyrsys B.V. и устанавливается в tools проекта. PATH пользователя и ассоциация .iss не изменяются. Установщик содержит лицензии всех компонентов из переданного комплекта. Inno Setup используется по его [лицензии](https://github.com/jrsoftware/issrc/blob/is-7_1_0/license.txt).

## Автоматическая проверка

```powershell
.\scripts\build-installer.ps1 -PayloadDirectory .\dist\installer-payload -TestIdentity
.\scripts\test-installer.ps1 -Installer .\dist\installer\AstraPDF-1.0.0-rc.3-setup-test-x64.exe -PayloadDirectory .\dist\installer-payload
```

Тестовый комплект имеет отдельные имя, EXE, AppId, ProgID, ярлыки и ветку регистрации. Тест отказывается запускаться при оставшейся тестовой установке. После сбоя сначала осмотрите результаты и удалите именно тестовую программу её деинсталлятором.

Проверяются реальная установка в путь с кириллицей и пробелами, исправление старой команды открытия, версия в Windows, ярлыки, точное совпадение файлов, повторная установка поверх испорченной DLL, отрисовка PDF с чистым PATH и удаление. Созданный тестом пользовательский PDF и действующий выбор PDF по умолчанию должны сохраниться. Отчёт и журналы остаются в отдельной папке test-output.

Для проверки обновления соберите старую версию комплекта с тем же `-TestIdentity` и передайте её как `-PreviousInstaller`. Новая установка выполняется без `/DIR`: она обязана найти предыдущий путь. Тестовый установщик не публикуется.

Для выпуска setup.1 на Windows 11 build 26300 проверены чистая установка и обновление rc.2 → rc.3, включая Windows PowerShell 5.1. В системном выборе программы для `.pdf` установлена доступность Astra PDF с собственной иконкой среди рекомендуемых приложений. На этой машине ссылка открыла общий список настроек; путь через поиск `.pdf` проверен. Автоматический тест не нажимает «По умолчанию».
