# Проверка 0.10.0-alpha.3 — 2026-10-03

## Изменение

Добавлены светлая и тёмная темы с кнопкой солнце/луна и пунктом меню «Вид → Тёмная тема». Выбор сохраняется в профиле Windows. Палитра применяется к заголовку, панелям, фону просмотра, меню, полям, собственным диалогам и иконкам Lucide.

Цвета самого PDF остаются исходными. Переключение темы не очищает изображения страниц, не запускает их повторную отрисовку и не меняет масштаб, прокрутку, поворот, видимость слоёв и состояние редактора. Кнопка доступна без открытого документа и во время правки текста.

## Проверки

- 83 успешных теста Rust; один необязательный сетевой тест пропущен. Проверены форматирование, Clippy и аудит зависимостей.
- Новые тесты проверяют сохранение выбора, восстановление после некорректного файла настроек и контраст текста в обеих палитрах.
- Семь проверок настоящего окна в `scripts/verify_theme.py`: последовательное переключение dark/light/dark; сравнение цветов снимка; неизменность состояния редактора, изображения PDF и счётчиков отрисовки; геометрия кнопки в узком и широком окне; сохранение обеих тем; неизменность исходного документа.
- При живой проверке через Computer Use выполнены переключение кнопкой, переключение через меню и открытие окна истории. Визуально проверены заголовок, панели, меню, подписи, иконки и содержимое PDF. В README добавлены настоящие снимки обеих тем.
- Полный сценарий `scripts/verify.ps1` прошёл чтение, слои, страницы, редактирование текста и объектов, шрифты, замечания, скрытие информации, сохранение, конфликты файлов, отмену/повтор и восстановление после сбоя.
- Сценарий отсутствия мерцания подтвердил сохранение готовых соседних страниц и миниатюр при локальных правках, отмене и повторе.
- Проверены синтетические документы до 1000 страниц и 300 слоёв, сканы, разные размеры листов и реальный A1 с 25 слоями. Для A1 проверены масштаб до 6400%, перемещение области просмотра, повторное использование готовых участков и неизменность исходного файла.
- Печать в PDF проверена независимым разбором результата: все страницы, диапазон из двух страниц, скрытый слой и поворот.
- 54 проверки установщика подтвердили обновление с alpha.2, версии в Windows и ярлыках, восстановление файлов, запуск без инструментов разработки, удаление только собственной регистрации и сохранение выбора приложения PDF по умолчанию.

Уточнены два ожидания старых проверок: цвет выделенной миниатюры берётся по выбранной теме; проверка размера пикселизации ждёт выполнения отложенной команды окна, прежде чем читать её результат.

## Ограничения доказательств

Системные полосы прокрутки и диалоги открытия/печати сохраняют оформление Windows. Цвета PDF не инвертируются, чтобы не искажать чертежи и результат печати.

Проверки приложения через сообщения Windows дополнены живой проверкой указанных сценариев темы. Они не подтверждают ручную приёмку каждого кадра, системного буфера обмена, сохранения выбранного диапазона через системный диалог печати, физического принтера и нескольких физических мониторов. Выпуск предварительный, без сертификата издателя.
