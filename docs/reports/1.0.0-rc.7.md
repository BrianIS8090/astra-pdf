# Проверка Astra PDF 1.0.0-rc.7

Дата: 2 октября 2026. Выпуск предварительный.

Среда: Windows 11 Домашняя x64, build 26300, масштаб 200%, Rust 1.99.0 GNU, PDFium 156.0.8076.0.

EXE: 1 723 392 байта; версия Windows 1.0.0.30007. SHA256: FA82E7DADCD550C154439FE27FA89CAF878729FBC86F506A237D5CD5D21854AE.

Полный прогон: `verify-20261002-141206-b91daf89`. Контрольные суммы исходников совпали до и после проверки. Частные документы, снимки, ключи и журналы с пользовательскими путями в публичный выпуск не включаются.

## Найденные и исправленные ошибки

- На реальном светотехническом альбоме замена строки смещала новый и соседний текст за пределы листа. Исправлены границы преобразований между потоками PDF и вставка замены в поток исходного объекта. Новый тест воспроизвёл ошибку до исправления; после исправления проверяются координаты и изображение соседей.
- После правки могли оставаться команды со ссылкой на удалённый ресурс шрифта. Ресурсы сохраняются. Poppler независимо отрисовал изменённую копию и копию с удалённым текстом без предупреждений; соседняя подпись совпадает с исходником по пикселям.
- Движение мыши при выделенном объекте могло создавать повторную перерисовку панели и задерживать таймер масштаба. Сообщения без активной рамки больше не перестраивают панель. Проверка включает увеличение при выделенном объекте и серию движений мыши.

## Ограничения

Пикселизация сохраняет средние цвета и общие очертания, поэтому не гарантирует секретность. Для конфиденциальных данных предусмотрено полное скрытие. Проверяйте границы и весь результат перед отправкой.

Очищенный PDF состоит из изображений при 300 dpi; он теряет поиск текста, слои и векторную детализацию. Исходник и зашифрованная копия с отдельным ключом остаются у владельца.

Редактирование ограничено объектами верхнего уровня и отдельными строками; исходное начертание и перевёрстка не сохраняются. Окончательное сохранение диапазона через интерактивный системный диалог печати, физические принтеры, другие конфигурации Windows и переход между мониторами не проверены. EXE не подписан сертификатом.
