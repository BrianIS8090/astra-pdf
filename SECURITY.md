# Безопасность

Astra PDF находится на стадии предварительного выпуска. Исправления безопасности планируются для актуальной опубликованной версии; старые кандидаты отдельно не поддерживаются.

Для сообщения об уязвимости используйте [приватное сообщение GitHub](https://github.com/BrianIS8090/astra-pdf/security/advisories/new). Укажите версию, условия воспроизведения и влияние. Не публикуйте конфиденциальные PDF, персональные данные и действующие ключи. Срок ответа пока не гарантируется.

Обработка документа выполняется в отдельном процессе с ограничением ресурсов. Это защита от некоторых сбоев, а не полноценная песочница безопасности: процесс имеет права текущего пользователя. Не считайте непроверенный PDF безопасным только потому, что он открылся в отдельном процессе.

JavaScript в PDF не выполняется; приложение не отправляет документы в сеть. Архивы пока не подписаны сертификатом издателя. SHA256 позволяет проверить целостность скачивания, но не заменяет цифровую подпись.
