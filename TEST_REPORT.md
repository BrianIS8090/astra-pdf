# Проверка Astra PDF 0.10.0-alpha.5

Предварительный выпуск. [Подробный отчёт](docs/reports/0.10.0-alpha.5.md) · [Предыдущий выпуск](docs/reports/0.10.0-alpha.4.md) · [Границы до 1.0](RELEASE_PLAN.md).

- 87 тестов Rust, форматирование, Clippy без предупреждений, аудит зависимостей без известных уязвимостей. Отдельный сетевой тест пропущен и не входит в это число.
- Девять групп проверок новых функций в настоящем окне: карандаш, отмена жеста, многострочный цветной текст, сохранение, выбранные страницы с несохранёнными замечаниями, шрифты, повторное редактирование, отмена/повтор, защита экспорта при наличии меток скрытия.
- Независимый Poppler подтвердил отображение красного штриха, синего и фиолетового текста в PDF и в выбранных страницах. pypdf проверил содержимое и встроенные шрифты.
- Семь проверок темы в настоящем окне: цвета панелей, переключение без повторной отрисовки PDF и сброса сеанса, доступность кнопки при ширине 560/980/1400, восстановление обеих тем после перезапуска, неизменность исходного PDF.
- Через Computer Use в живом окне alpha.5 проверены выбор цвета, создание штриха, ввод кириллической надписи, Ctrl+S и сохранение первой/третьей страниц через системный диалог сохранения. Результат разобран независимо: две страницы, два рисунка и три текстовые заметки. Новый основной снимок README сделан в этом окне.
- Полный прогон настоящего окна проверил чтение, страницы, текст, шрифты, замечания, сохранение, отмену/повтор, скрытие информации, отсутствие мерцания при правках и восстановление после сбоя. Сохранённые PDF дополнительно проверены независимыми библиотеками.
- Корпус включает 1000-страничный текст, сканы, разные размеры страниц, 300 слоёв и реальный восьмистраничный технический альбом из сообщения об ошибке. Проверен режим точных деталей до 6400%; исходный альбом не изменён.
- Обновление с alpha.4 прошло 54 проверки установщика с отдельной тестовой регистрацией: версии и ярлыки, восстановление файлов, удаление и сохранение выбора программы PDF по умолчанию.

**Границы проверки:** системные полосы прокрутки и диалоги открытия/печати используют оформление Windows. Ручная приёмка системного буфера обмена, сохранения диапазона через системный диалог печати, физического принтера и нескольких физических мониторов остаётся открытой. Автоматические проверки DPI не заменяют физические мониторы. Сертификата издателя нет, выпуск неподписан.

В публичных снимках используются вымышленные данные. Реальные пользовательские PDF и снимки их содержимого не входят в репозиторий.
