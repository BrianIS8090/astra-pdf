# Подпись издателя Windows

Сборка поддерживает Authenticode для приложения и установщика. Без сертификата выпуск остаётся неподписанным; собственный недоверенный сертификат не используется.

1. Установите сертификат подписи программ с закрытым ключом в личное хранилище текущего пользователя Windows. Для аппаратного ключа или облачного сертификата требуется его официальный поставщик ключей.
2. Установите Windows SDK с `signtool.exe`.
3. Задайте `ASTRA_SIGN_CERT_THUMBPRINT` — отпечаток сертификата. При необходимости задайте абсолютный путь `ASTRA_SIGNTOOL` и адрес службы меток времени `ASTRA_TIMESTAMP_URL`.
4. Обычные сценарии сборки комплекта и установщика подпишут файлы до вычисления контрольных сумм. При ошибке подписи выпуск остановится.

Сертификат и закрытый ключ не помещаются в репозиторий. Подписанную сборку нужно проверять заново: подпись меняет байты EXE. Тестовое окружение без доступа к ключу проверяет неподписанную сборку и не подтверждает доверие Windows.

Проверка обновлений использует защищённое соединение с GitHub и контрольную сумму SHA-256 из сведений об опубликованном установщике. Это отдельная проверка целостности; она не заменяет подпись издателя Windows.
