# Проверка Astra PDF 0.10.0-alpha.1

Предварительный выпуск. [Подробный отчёт](docs/reports/0.10.0-alpha.1.md) · [Границы до 1.0](RELEASE_PLAN.md).

- 78 тестов Rust и отдельная проверка соединения с GitHub прошли; Clippy и аудит зависимостей без предупреждений.
- Сценарии в настоящем окне проверили чтение, редактор, страницы, замечания, сохранение, отмену/повтор и восстановление после сбоя. Результаты PDF дополнительно проверены независимыми библиотеками.
- На реальных альбомах 11/48 страниц и A1 с 25 слоями проверены масштаб до 6400% и сохранность исходников. Первый кадр: 51/84/1527 мс в измеренном прогоне.
- Обновление установщиком с прежней rc.9 прошло 54 проверки; регистрация PDF и пользовательский выбор сохранены.

**Ручная приёмка остаётся открытой:** доступ к рабочему столу не позволил проверить обычные жесты, системный буфер обмена и сохранение диапазона через системный диалог печати. Автоматический DPI-тест не заменяет физические мониторы. Сертификата издателя нет, выпуск неподписан. Стабильная версия 1.0 не объявлена.

В публичных снимках используются только вымышленные демонстрационные данные. Реальные пользовательские PDF, снимки их содержимого и полные локальные отчёты остаются вне репозитория.
