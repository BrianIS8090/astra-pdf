# Проверка Astra PDF 1.0.0-rc.3

Дата: 2 октября 2026. Статус: предварительный выпуск. Окончательная приёмка сохранения диапазона через системный диалог печати остаётся незавершённой.

Среда: Windows 11 Домашняя x64, build 26300, масштаб 200%; Microsoft Print to PDF; Rust 1.99.0 GNU; PDFium 156.0.8076.0.

Проверенный EXE: 1 351 168 байт. SHA256: `F32554CB1A80805C4C60CBD1F6DFBE4E2C4328190CE620FFB9F985CF710B793B`.

Идентификатор полного локального прогона: `verify-20261002-073922-8ede93ac`. Исходники реализации совпали до и после проверки. Частные документы, их снимки и локальные журналы в публичный выпуск не включаются. [Отчёт rc.2](docs/reports/1.0.0-rc.2.md) сохранён отдельно.

## Результаты

- **27 тестов Rust** пройдены, включая настоящую отрисовку PDFium, слои, геометрию, ограничения памяти, повороты, печатные ошибки и передачу данных между процессами. Форматирование и clippy с запретом предупреждений пройдены.
- **24 сценария окна**: миниатюры и их пиксели, переходы, непрерывная прокрутка, оба режима расположения страниц, быстрые команды масштаба без исчезновения обзора, поле номера, иконка, слои, клавиатура, поворот, открытие/отмена диалогов, повреждённые и парольные PDF, восстановление, Unicode, изменение размеров, отмена и закрытие при печати, уничтожение дочернего движка вместе с приложением.
- **10 проверок детального режима** на синтетическом A1 и дополнительном архитектурном A1 с 25 слоями: обычный режим по умолчанию, переключение туда и обратно, увеличение 100–6400%, сохранение обзора, готовность всех видимых участков, ограничение памяти, перемещение и возврат, поворот и неизменность исходника. Различимость линий толщиной 0,01 пункта проверена по фактическим пикселям окна: 74 перехода на контрольном отрезке при 6400%.
- Участки сопоставлены с полной отрисовкой при всех четырёх поворотах и разных состояниях слоёв. Проверены стыки, границы страницы и отказ при неверных координатах. Участок 256×256 нарисован для виртуальной страницы 500 000×700 000 без выделения изображения всей страницы.
- Проверены сбой, зависание, превышение памяти движка в 1 ГиБ, отмена и восстановление. Изменённый исходник требует повторного открытия.
- Настоящая GDI-печать в Microsoft Print to PDF: три страницы всего документа и две выбранные страницы со скрытым слоем и поворотом. Независимое чтение PDF подтвердило количество, различие страниц, ориентацию и пиксели слоёв.
- Переносимая папка запускается без Rust с системным PATH и PDFium рядом с EXE.
- RustSec: 68 зависимостей, 1279 записей базы, 0 известных уязвимостей и предупреждений. Коммит базы: `6de4455103aced2cba86e3b86e5c090b22827cf1`. Это проверка Rust-зависимостей, а не полный аудит PDFium.

## Визуальная проверка

Осмотрены снимки настоящих окон. Через Computer Use на окончательном EXE проверены список режимов, выбор «Чертёж — точные детали», Ctrl+1 и прокрутка архитектурного листа. Во время уточнения обзор оставался видимым; после завершения размеры, подписи и линии были чёткими. Интерфейс использует системную рамку Windows и собственную иконку.

## Измерения

На дополнительном A1 (696 КБ, 25 слоёв) первая страница появилась за 3,65 с. Последовательности команд увеличения до 104%, 434%, 1647% и 6400%, включая отправку команд проверяющей программой и ожидание всех участков, заняли 1192, 888, 782 и 888 мс соответственно. Это длительность серии команд, не одного шага масштаба.

Перемещение к новой области при 6400% — **202 мс**, возврат к готовой области — **25 мс**. Изображения участков занимали не более 64 МиБ. Пиковый замеченный рабочий набор двух процессов — 237 297 664 байта (226,3 МиБ).

| Документ | Первая страница | Память двух процессов после навигации |
|---|---:|---:|
| Текст, 1000 страниц | 156 мс | 103,7 МиБ |
| Сканы, 27,5 МБ | 272 мс | 186,7 МиБ |
| Смешанные размеры | 81 мс | 98,0 МиБ |
| 300 слоёв | 196 мс | 96,2 МиБ |
| Глубокая вложенность | 67 мс | 81,7 МиБ |

Отдельное трёхкратное сравнение обычного режима перед последней оптимизацией детального режима не показало замедления относительно rc.2: медиана первого изображения 3551 против 3830 мс; одного шага увеличения — 2208 против 2799 мс. Обычный путь отрисовки после сравнения не менялся. Дисковый кэш не сбрасывался; результаты не являются гарантией для любых PDF и компьютеров.

## Ограничения

Физические принтеры, дуплекс, цветопередача, аппаратные копии, переход между мониторами с разным DPI и другие сборки Windows не проверены. Сохранённый диапазон именно из системного диалога ещё требует независимого сопоставления, поэтому `native_print_range_acceptance` остаётся `pending`.

Пакет не подписан сертификатом. Нет поиска и выделения текста, парольных PDF, редактирования, заполнения форм и печати 1:1. Детальный режим относится к экрану; печать остаётся растровой. Сканы не получают деталей, которых нет в исходном изображении. Геометрия страницы ограничена 1 млн пикселей на сторону, масштаб — 6400%; для очень длинной ленты предел ниже.

Публичные архивы отдельно проверяются после извлечения; их контрольные суммы и коммит исходников указаны в `RELEASE.json` и `SHA256SUMS.txt`.
