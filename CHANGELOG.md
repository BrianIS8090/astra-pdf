# История изменений

## 1.0.0-rc.2 — 2026-10-02

Первый публичный предварительный выпуск Astra PDF для Windows 11 x64.

### Просмотр

- Миниатюры страниц с загрузкой по мере просмотра и переходом по нажатию.
- Непрерывная прокрутка документа и отдельный режим одной страницы.
- Масштаб без исчезновения страницы: сохранение изображения до завершения перерисовки, объединение быстрых команд, сохранение точки под курсором.
- Переход по номеру, поворот, вписывание страницы и масштаб по ширине.
- Управление настоящими PDF-слоями, их блокировками и взаимоисключающими группами.

### Windows

- Нативный интерфейс на Rust, собственная иконка и центрирование поля номера страницы.
- Системный диалог печати, выбранные слои и поворот, отмена задания.
- Переносимый ZIP без установки и прав администратора; PDFium входит в пакет.
- Отдельный процесс обработки PDF с ограничениями памяти и времени запроса.

### Проверка и ограничения

22 теста Rust, 23 сценария окна, проверки сбоев движка, виртуальной печати и запуска распакованного приложения пройдены. Подробности и измерения — в [TEST_REPORT.md](TEST_REPORT.md).

Это кандидат в выпуск: окончательное сохранение диапазона через системный диалог ещё не подтверждено. Физические принтеры не проверены, приложение не подписано сертификатом. Нет поиска и выделения текста, открытия PDF с паролем, редактирования, заполнения форм и печати в масштабе 1:1.
