# Проверка Astra PDF 0.10.0-alpha.2

Предварительный выпуск. [Подробный отчёт](docs/reports/0.10.0-alpha.2.md) · [Предыдущий выпуск](docs/reports/0.10.0-alpha.1.md) · [Границы до 1.0](RELEASE_PLAN.md).

- 81 тест Rust; Clippy и аудит зависимостей без предупреждений. Отдельный сетевой тест не входит в это число.
- Сценарии в настоящем окне проверили чтение, редактор, страницы, замечания, сохранение, отмену/повтор и восстановление после сбоя. Результаты PDF дополнительно проверены независимыми библиотеками.
- Новый сценарий окна проверяет отсутствие пустого кадра, сохранение позиции, масштаба, геометрии и списка миниатюр при правках и отмене/повторе. Счётчики отрисовки соседних страниц не увеличиваются; изменённая страница действительно получает новый кадр.
- Корпус реальных PDF: альбомы 11/48 страниц и A1 с 25 слоями. Проверки идут на копиях; исходники проверяются побайтно.
- Обновление с 0.10.0-alpha.1 прошло 54 проверки установщика с отдельной тестовой регистрацией; выбор программы PDF не изменён.

**Ручная приёмка остаётся открытой:** Computer Use смог открыть диалог, но дальнейшее управление не прошло (`element ... is not available in cached app state`, `failed to activate captured window`). Сценарии выполняются в настоящем окне через сообщения Windows. Они не подтверждают ручной просмотр каждого кадра, системный буфер обмена и сохранение диапазона через системный диалог печати. Автоматический DPI-тест не заменяет физические мониторы. Сертификата издателя нет, выпуск неподписан.

В публичных снимках используются вымышленные данные предыдущей alpha.1; оформление интерфейса в alpha.2 не менялось. Реальные пользовательские PDF, снимки их содержимого и полные локальные отчёты остаются вне репозитория.
