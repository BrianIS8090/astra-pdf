# Проверка Astra PDF 1.0.0-rc.2

Дата: 2 октября 2026, Asia/Yekaterinburg. Статус: кандидат в выпуск; окончательная приёмка системного сохранения печати не закрыта.

Среда: Windows 11 Домашняя x64, 10.0.26300, масштаб 200%; Microsoft Print to PDF. Rust 1.99.0 GNU, PDFium 156.0.8076.0, lopdf 0.45.0.

Проверенный EXE: 1 326 592 байта. SHA256: `84FE043889FD2D7F10B9615A5213044F9D60C413CD653B24B2B9199CAD782D08`.

Полный свежий прогон: `test-output\verify-20261002-065843-504f8d2e`.

## Изменения по замечаниям пользователя

- Настоящие миниатюры страниц: загрузка только видимого участка панели и ближайших элементов; нажатие открывает нужную страницу. Выбор и видимая подсветка согласованы с полем номера и прокруткой.
- Непрерывная лента страниц включена по умолчанию; соседние страницы одновременно видны на границе. Есть переключение в режим одной страницы. Колесо и полоса прокрутки работают по всему документу.
- Изменение масштаба сохраняет предыдущее изображение до готовности нового. Кнопки используют шаг 10%, Ctrl+колесо — 8% на полный шаг колеса; повторные команды объединяются с задержкой 65 мс. Центр просмотра или точка под курсором сохраняется. Это смена масштаба с временным растяжением изображения, а не отдельная кадровая анимация.
- Номер страницы выровнен горизонтально и вертикально; ввод, выделение и Enter проверены. Исправлена устаревающая подсветка миниатюры после перехода по номеру.
- Добавлена собственная иконка с девятью разрешениями 16–256 пикселей; она встроена в EXE. Иконка окна и панели задач видна при интерактивной проверке.
- Активная вкладка панели выделена. В достаточно широком окне кнопки располагаются в один ряд; в узком — в два. Во время печати открытие другого документа отключено.

## Автоматические проверки

- 22 теста Rust; форматирование и clippy с запретом предупреждений пройдены.
- 23 сценария настоящего окна. Проверены миниатюры и нажатие, две страницы в общей области, начало/конец документа, оба режима просмотра, быстрый масштаб без исчезновения предварительного изображения, выравнивание поля и иконка, слои и их сброс, закреплённые и взаимоисключающие слои, номер и клавиатура, поворот, открытие/отмена диалогов, повреждённый/пустой/парольный PDF и восстановление, перетаскивание Unicode-пути, изменение размеров, отмена печати, закрытие во время печати и уничтожение дочернего движка при завершении родителя.
- Подсветка миниатюры после программного перехода проверена по фактическому цвету пикселя снимка окна, а не только по внутреннему номеру страницы.
- Корпус: 1000 текстовых страниц, восемь растровых сканов 27,5 МБ, смешанные размеры включая A0, 300 слоёв и 10 380 уровней вложенности. Исходные документы остались неизменными.
- Проверены аварийное завершение, зависание, ограничение памяти движка в 1 ГиБ, отмена и восстановление, отказ восстановления после изменения исходного файла.
- Настоящая GDI-печать в Microsoft Print to PDF: весь документ и диапазон со скрытым слоем и поворотом. Независимое чтение PDF подтвердило число и различие страниц, ориентацию и отсутствие выключенного слоя по пикселям.
- Тесты печатного устройства проверяют ошибки на каждом этапе и отмену без ложного сообщения об успехе.
- Папка запускается без Rust, с системным PATH и PDFium рядом с EXE. Контрольные суммы исходников совпали до и после прогона.
- RustSec: 68 зависимостей, 1279 записей базы; 0 известных уязвимостей и предупреждений. Коммит базы: `6de4455103aced2cba86e3b86e5c090b22827cf1`. Это проверка Rust-зависимостей, не полный аудит PDFium.

## Интерактивная и визуальная проверка

Через Computer Use в работающей Windows проверены открытое окно, нажатие второй миниатюры, прокрутка через границу страниц, Ctrl+плюс, ввод номера 3 с Enter, вкладка слоёв, выключение и сброс слоя. В окончательной сборке осмотрены однострочная панель, активная вкладка, миниатюры, центрирование номера и иконка. Дополнительно просмотрены снимки 1120×1040 и 1800×1200 при DPI 192; все основные кнопки доступны. Снимки WM_PRINT не передают современную системную рамку DWM; она отдельно наблюдалась через Computer Use.

Системный диалог печати окончательного EXE принял диапазон 2–3 для Microsoft Print to PDF и открыл «Сохранение результата печати». Завершить сохранение через Computer Use не удалось: инструмент не смог адресовать элемент вложенного диалога (`element 135 is not available in cached app state for AstraPDF.exe`). В диалоге открытия также наблюдалась ошибка инструмента `failed to activate captured window`. Эти ошибки не объявляются дефектами приложения или успешной приёмкой. Тестовый процесс закрыт; в очереди Microsoft Print to PDF заданий не осталось.

Сохранённый PDF именно из системного диалога пока не получен и не сопоставлен с контрольными страницами. Поэтому `native_print_range_acceptance` остаётся `pending`. Автоматическая GDI-печать подтверждена отдельно и не заменяет этот пользовательский сценарий.

## Ограничения выпуска

Физические принтеры, дуплекс, цветопередача, аппаратные копии, перенос между мониторами с разным DPI и другие сборки Windows не проверены. Сертификата издателя нет. Поиск/выделение, парольные PDF, редактирование, формы и печать 1:1 не входят в эту версию. При очень большом масштабе экранная страница ограничена 8 млн пикселей и увеличивается из этого разрешения.

Упаковка сверяет исходники и EXE с результатом проверки, проверяет файлы после распаковки архива и запуск распакованного приложения. Архивы и их SHA256 перечисляются в RELEASE.json рядом с выпуском. Стабильная версия без rc не допускается без завершённой приёмки системной печати.
