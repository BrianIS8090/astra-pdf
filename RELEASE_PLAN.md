# Правила предварительного выпуска

Текущая ветка продукта — **0.10.0-alpha.5**. Серия 1.0.0-rc.1–rc.9 сохранена в истории, но официального 1.0 не было. Новые выпуски остаются предварительными, пока не закрыты условия ниже.

## Для каждого предварительного выпуска

1. Одна версия в Cargo, ресурсе EXE, заголовке, CHANGELOG, комплекте, установщике и ярлыках.
2. Проверка форматирования, Clippy без предупреждений, тесты Rust последовательно, аудит зависимостей.
3. Полная проверка настоящего окна: чтение, масштаб, слои, редактирование, страницы, замечания, отмена/повтор, сохранение и ошибки. Восстановление проверяется принудительным завершением только собственного тестового процесса.
4. Реальные PDF проверяются на копиях, контрольные суммы исходников не меняются. Частные документы и их снимки не публикуются.
5. Пакет создаётся только из проверенного EXE с неизменёнными исходниками; распакованный ZIP повторно открывает PDF.
6. Изолированный установщик: установка, восстановление файлов, обновление предыдущего выпуска, регистрация PDF, ярлыки и удаление без изменения UserChoice.
7. GitHub release имеет `prerelease=true`, `latest=false`, историю изменений и явно перечисленные ограничения. Публикуются установщик, переносимый ZIP, исходники и контрольные суммы.

## До стабильного выпуска

- Ручная приёмка мышью и клавиатурой: все инструменты, перетаскивание миниатюр, буфер обмена, доступность и работа с диалогами.
- Выбранный диапазон через системный Microsoft Print to PDF: правильное число страниц и содержимое после сохранения. Отдельно физическая печать на согласованных устройствах.
- Настоящие мониторы 100/125/150/200%, перенос окна между ними. Автоматическая отправка события смены DPI не заменяет этот пункт.
- Доверенная Authenticode-подпись, чистая установка на другой Windows 11, сценарии обновления и отката.
- Расширенная совместимость PDF: документы других генераторов, нестандартные шрифты, повреждённые файлы, большие наборы слоёв и страниц.

Пройденные автоматические проверки не закрывают отсутствующую ручную приёмку. Если рабочий стол недоступен, ограничение фиксируется в отчёте; стабильная упаковка запрещена. Подготовленная поддержка подписи без сертификата не означает подписанный выпуск.
