# Проверка 0.10.0-alpha.1

Предварительный выпуск, Windows 11 x64 10.0.26300. Версия не объявляется стабильной 1.0.

SHA-256 проверенного EXE: `fbab7ea25ff270b138ef5bdfb4888c591b0be9d67400a5693459f94199bf2998`.

## Код и файлы PDF

- 78 тестов Rust прошли последовательно. Отдельный сетевой тест GitHub HTTPS и сведений об установщике также прошёл.
- Форматирование и Clippy без предупреждений. RustSec: 0 уязвимостей, 0 предупреждений по закреплённым зависимостям. Неподдерживаемый ttf-parser заменён на Skrifa.
- Проверены шрифты, кириллица, многострочный текст, текст внутри повторно используемых групп и слоёв, положение соседних объектов, перемещение/размер, страницы, аннотации, шифрование, восстановление и ограничение истории.
- Независимое чтение результатов через pypdf и pdfplumber подтвердило сохранение текста, оформления, размеров и аннотаций. Очищенный экспорт проверен на отсутствие исходных объектов, вложений и метаданных; восстановленный оригинал совпадает побайтно.

## Запущенное приложение

Сценарии управляют отдельным настоящим окном Windows и считывают состояние приложения; снимки окна просмотрены визуально. Это автоматизация приложения, а не ручной проход мышью и клавиатурой.

Проверены: поиск кириллицы, переходы между результатами, выделение, ссылки, закладки, возврат к месту чтения в новом процессе, отмена/повтор, аварийное восстановление PDF и скрывающих блоков, удаление временных незашифрованных снимков после сбоя, вставка/дублирование/удаление/перестановка страниц, объединение, текстовый предпросмотр, выбор шрифта, несколько строк, перемещение и размер, шесть видов замечаний, масштаб измерения, изменение и удаление комментариев.

Сценарии сохранения отдельно проверяют: отсутствие лишних пользовательских копий, Ctrl+S/«Сохранить как», отмену диалога, внешний конфликт, ошибку записи, закрытие/открытие с сохранением или отказом, сохранение истории после записи.

Реальные документы: светотехнический альбом 11 страниц, технический альбом 48 страниц, чертёж A1 с 25 слоями. Исходные файлы не изменены и не включены в репозиторий. Дополнительно проверены синтетические 1000 страниц, сканы, разные размеры листов, 300 слоёв и вложенные объекты.

Набор зафиксирован в [performance-corpus.json](../performance-corpus.json). Прогон `verify-20261002-235037-af37913b`, одна локальная машина. Первый кадр отсчитывается внутри приложения; это не полное время запуска процесса.

## Установка и версия

Изолированное обновление **1.0.0-rc.9 → 0.10.0-alpha.1** прошло 54 проверки. Сохранились путь установки и выбор PDF по умолчанию; версия изменилась в EXE, регистрации и ярлыках. Повторная установка восстановила повреждённый служебный файл. Удаление тестовой программы сохранило пользовательский PDF и рабочую регистрацию Astra PDF.

Сборка умеет подключать сертификат издателя; проверены синтаксис сценария подписи и отказ обязательной подписи без сертификата. Доверенного сертификата нет, выпуск неподписан. Фактическая подпись сертификатом не подтверждена.

## Оставшиеся границы приёмки

- Компьютерное управление не смогло активировать окно: снимок рабочего стола возвращал фон. Ручные жесты, системный буфер обмена (Win32 error 5) и перетаскивание миниатюр требуют повторения в доступном рабочем столе.
- Проверка компоновки при 100/125/150/200% выполнена событием смены DPI. Переход между физическими мониторами не подтверждён.
- Виртуальная печать всех страниц и двух выбранных страниц прошла независимое сравнение. Но **сохранение выбранного диапазона через системный диалог** не принято; `native_print_range_acceptance=pending`. Физический принтер не тестировался.
- Получение GitHub-метаданных проверено по настоящему HTTPS. Полный пользовательский цикл загрузки и запуска будущего обновления ещё требует ручной приёмки.

Ограничения функций перечислены в README и встроенной справке: нет автоматической перевёрстки абзацев и OCR, вложенные нетекстовые элементы изменяются целой группой, часть PDF с формами и сложными шрифтами отклоняется. Пикселизация оставляет информацию о цветах; для секретных данных предназначено полное скрытие с очищенным экспортом.
