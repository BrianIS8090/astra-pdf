# Проверка 0.10.0-alpha.4 — 2026-10-03

## Исправление

Общий обработчик цветов, добавленный вместе с темами, устанавливал прозрачный фон текста для нативного поля EDIT. При частичном обновлении строки во время ввода старые символы могли оставаться под новыми. Полям EDIT возвращён непрозрачный режим рисования с цветом фона выбранной темы. Это относится и к полям только для чтения, которые используют другое сообщение Windows.

Изменение не затрагивает PDF, шрифты документа и изображение страницы. Поля очищают изменённую область при своей обычной перерисовке.

## Проверки

- До исправления новый тест `edit_fields_erase_previous_glyphs_in_both_themes` завершался ошибкой: вместо OPAQUE поле использовало TRANSPARENT. После исправления тест прошёл для обеих тем и для редактируемого поля/поля только для чтения.
- 84 теста Rust прошли; один необязательный сетевой тест пропущен. Форматирование, Clippy и аудит зависимостей прошли.
- Полный сценарий настоящего окна проверил редактирование текста, сохранение шрифтов, многострочный предпросмотр, отмену/повтор, страницы, замечания, пикселизацию, сохранение и конфликты файлов, отсутствие мерцания при правках, поиск, слои, масштабирование, восстановление после сбоя и виртуальную печать.
- Проверены синтетический корпус и реальный восьмистраничный технический альбом из сообщения об ошибке, включая просмотр до 6400%. Исходный PDF не изменён и не публикуется.
- Повторно прошли семь проверок тем, сохранения выбора и неизменности состояния документа.
- 54 проверки установщика прошли обновление с alpha.3, регистрацию и версии в Windows, восстановление файлов, запуск, удаление и сохранение выбора приложения PDF по умолчанию.

## Границы доказательств

Новый тест проверяет режим рисования настоящего элемента Windows, но не сравнивает каждый пиксель при наборе текста. Общие сценарии выполняются в настоящих окнах через сообщения приложения.

Живая визуальная проверка исправления через Computer Use осталась незавершённой: пользователь остановил управление клавишей Esc. Снимки тем в README относятся к alpha.3; они не выданы за подтверждение исправления alpha.4.

Ручная приёмка системного буфера обмена, сохранения диапазона через системный диалог печати, физического принтера и нескольких физических мониторов остаётся открытой. Выпуск предварительный, без сертификата издателя.
