Astra PDF — установка в Windows 11 x64

Установка выполняется для текущего пользователя, без прав администратора.
Обычный путь: %LOCALAPPDATA%\Programs\Astra PDF
Повторный запуск установщика обновляет программу в той же папке.

PDF по умолчанию

В конце установки оставьте флажок «Выбрать Astra PDF для PDF по умолчанию».
В параметрах Windows нажмите .pdf, выберите Astra PDF и подтвердите выбор.
Если открыт общий список, введите .pdf в самом верхнем поле и нажмите
Enter, затем нажмите текущее приложение, выберите Astra PDF и
«Задать по умолчанию».
Позднее это окно доступно через меню Пуск → Astra PDF →
«Выбрать для PDF по умолчанию» или Параметры → Приложения →
Приложения по умолчанию → Astra PDF.

Windows требует подтверждать смену приложения по умолчанию в системном
окне. Установщик не обходит эту защиту и не меняет выбор скрытно.
Новая регистрация «Открыть с помощью» ведёт к установленной программе,
даже если раньше в Windows был выбран EXE из распакованного архива.

Обновление и удаление

Закройте Astra PDF и запустите новый установщик. Удалять предыдущую
установленную версию не нужно. Старую переносимую копию можно оставить;
она не обновляется. Собственные PDF храните вне папки программы.
Удаление: Параметры → Приложения → Установленные приложения → Astra PDF.
Удаляется только установленный комплект и его регистрация.

Выпуск 1.0.0-rc.3 предварительный. Известные ограничения приложения
перечислены в README.md и TEST_REPORT.md рядом с программой.
Установщик и приложение не имеют подписи коммерческого издателя.
