# Объём 0.10.0-alpha.1

Этот цикл остаётся предварительным. Официальная версия 1.0 ещё не объявлена.

Согласованный объём работы:

- [x] Повтор отменённых действий, Ctrl+Y и Ctrl+Shift+Z.
- [x] Зашифрованная рабочая копия восстановления после сбоя.
- [x] История действий, проверка повтора и восстановления в запущенном приложении.
- [x] Поиск, выделение и копирование текста, ссылки, закладки.
- [x] Недавние документы и восстановление места чтения.
- [x] Перестановка миниатюр, удаление, дублирование, вставка страниц, объединение PDF.
- [x] Редактирование непосредственно на странице, предварительный просмотр.
- [x] Многострочный текст, группы и слои, перемещение и размер объектов.
- [x] Явный выбор шрифта при отсутствии нужных символов.
- [x] Комментарии, стрелки, прямоугольники и маркер.
- [x] Измерение длины и площади с масштабом чертежа.
- [x] Проверка обновлений и просмотр изменений перед установкой.
- [x] Поддержка подписи установщика; доверенная подпись требует сертификата издателя.
- [x] Автоматизация настоящего окна на реальных PDF, при маленькой ширине и изменении масштаба интерфейса.

Отдельная приёмка перед стабильным выпуском:

- [ ] Полный проход мышью и клавиатурой в доступном рабочем столе, включая перетаскивание миниатюр и системный буфер обмена.
- [ ] Сохранение выбранного диапазона через системный диалог Microsoft Print to PDF; физический принтер отдельно.
- [ ] Переход между физическими мониторами с разным DPI (плотностью интерфейса).
- [ ] Доверенный сертификат издателя и проверка подписанного установщика на чистой Windows.

Сценарии управления страницами, текста, замечаний и навигации включены в общий проверочный запуск. Три реальных документа зафиксированы контрольными суммами в наборе производительности; публичная документация содержит обезличенные результаты. Выпуск, упаковка и доказательства установки описаны в TEST_REPORT.md.

Исходные пользовательские PDF не входят в публичный репозиторий. Проверки выполняются на копиях. Автоматические проверки и лично просмотренные окна отмечаются отдельно.
